# Geeks360 Claude skills

The Claude Code skills we use at Geeks360 for client work: ads, websites, SEO, email and agent workflows.
A skill is a packaged set of instructions Claude loads when a task matches it.

Updated 24 Oct 2026. 19 skills.

## Ads and creative

| Skill | What it does |
|---|---|
| `meta-ad-creatives` | End-to-end process for Meta (Facebook and Instagram) ad creatives: brief, research, idea plan, photos, statics, Stories, carousels, video, review rounds, packaging and handoff. Includes design rules, copy rules and a profile per brand. |
| `static-ad-design` | Rules and a reference library for static paid-social ads (Feed, Stories, Reels) that look like top-performing ads, not agency templates. |
| `blog-hero-image-prompt-generator` | Three concept directions with full prompts for AI-generated blog hero images. |
| `launch-video` | A motion-graphics launch or promo video with music for a product, CLI or library, built from its repo. |

## Websites

| Skill | What it does |
|---|---|
| `build-wp-acf-site` | WordPress sites on a clean custom ACF Pro theme: flexible-content page sections, acf-json as the source of truth. |
| `client-site-design` | HTML-first page design for client websites before WordPress, so every page stays in one style. Also used when agents produce pages or graphics. |
| `marketing-pages` | Rulebook for marketing site pages by class (campaign landers, product pages, programmatic SEO, editorial): attribution, navigation, sitemap and robots, indexing, conversion. |
